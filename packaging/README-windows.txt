DevTrack for Windows

Start DevTrack.exe. No installation is needed: you can keep it in any folder, for example
in "C:\Users\<you>\AppData\Local\Programs\DevTrack", and pin it to Start or the taskbar.

The first time, Windows may show "Windows protected your PC" because this version is not
signed yet: choose "More info", then "Run anyway".

Your data is kept in %APPDATA%\DevTrack on this computer.
